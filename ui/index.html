Reproducibility details

Research context

Stream ETL framework

Ismail et al. describe a multi-component Twitter stream ETL framework using Kafka, Spark, Cassandra, HBase, Hive, and HDFS, with sentiment analysis, bias handling, and geospatial visualization.

This project implements a smaller Spark-only path, then compares classifiers and local replay performance. It compares design and measured trends, not absolute benchmark values from the paper.

Open publisher article ↗Publisher abstract reviewed; detailed paper dataset sizes and benchmark tables were not verified.
Data limitation

Historical and noisy labels

Sentiment140 is from 2009. Labels were assigned through distant supervision and do not provide human-verified sentiment for each tweet.

System limitation

One machine

Local core comparisons describe this laptop and a finite file replay. They do not establish distributed cluster scaling or live-feed latency.

Scope boundary

No live platform feed

No Kafka, HDFS, public API ingestion, geolocation, or identifiable user reporting was included.
